# 误杀放行名单（白名单）
#
# 作用：build.py 会把本文件里生效的行，生成为模块 [Rule] 段的**最前面**部分。
#       规则自上而下、命中即停，所以放行必须排在所有 REJECT 之前才会生效。
#
# 生效后要做什么：把本文件改动 push 回仓库 → GitHub Actions 自动重建 modules/*.module。
#                 也可以直接在 GitHub 网页上编辑本文件，效果一样。
#
# 写法（三选一，行内 # 之后是注释）：
#   example.com                      → 生成 DOMAIN-SUFFIX,example.com,DIRECT
#   DOMAIN-KEYWORD,某个关键词        → 生成 DOMAIN-KEYWORD,某个关键词,DIRECT
#   DOMAIN,exact.example.com         → 生成 DOMAIN,exact.example.com,DIRECT
#   已经写全策略的行（含 ,DIRECT）原样保留
#
# 怎么知道该放行什么：
#   装了模块之后某个 App 不好用了 → 在小火箭「配置 → 编辑配置 → 规则 → 测试规则」
#   里输入可疑域名，看是不是命中了 REJECT；确认是被误杀，就加到下面。
#   ⚠️ 不要凭感觉加。白名单加错 = 广告照旧。
#
# ============================================================
# 一、默认放行（有明确依据，建议保留）
# ============================================================
# 依据：这三条的「按后缀拦截」会造成功能性影响，且上游 curators 自己也把它们列进了
#       需要人工判断的清单（LOWERTOP 的 AntiAD.list 里对应行是注释掉的）。
#

app-analytics-services.com
